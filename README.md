# sabeq.legal

www.sabeq.legal shows https://q8-ux.github.io/saad/sabeq-legal/ in a full-screen frame.
The frame is used because the site's backend (sabeq-legal-public.centrino.chatgpt.site)
only accepts requests from https://q8-ux.github.io. Any change pushed to
`Q8-ux/saad/sabeq-legal` appears on www.sabeq.legal immediately — nothing to sync here.
